边端运行配置

监听关 = 该平台本轮不巡检；自动发送关 = 仍可识别/生成回复但只进 pending 不发出。保存后下个 tick 生效，无需重启。

查单配置写入 systems.order，保存后下个 tick 生效（无需重启）。OpenClaw 浏览器需已登录该后台。

默认：白名单留空 + 仅白名单=关 → 回复所有有未读/待回的顾客。灰度时填白名单并打开「仅白名单」。

升级通知 · 企微群

转人工时推送到企微内部群。开关与 Webhook 只在本页配置（写入 cs-runtime.json）。获取地址：内部群 → 右上角 ··· → 添加群机器人 → 复制 Webhook。

启用=开 且地址非空才会推送。点上方「保存到 cs-runtime.json」一并保存；巡检热读，下个消息生效。

OpenClaw LLM（对话模型）

配置 Gateway 使用的 API Key、Base URL 与主模型。写入便携包 data\.openclaw\；密钥不回传，留空=不改。

环境变量（.env）

可在此改边端 / 中台常用变量；密钥字段不回传明文，留空=不修改。保存后需重启 Start-All（及 rag-service）才完全生效。对话模型请用上方「OpenClaw LLM」。
